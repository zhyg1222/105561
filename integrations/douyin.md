# 抖音接入

## 官方能力

- 内容发布：抖音开放平台“发布内容至抖音”，需要应用权限和用户 OAuth 授权。
- 私信：官方私信接口，账号类型和权限有额外要求。
- 直播互动：直播玩法/直播伴侣体系，不是普通网页 API。
- 不能依赖消费端逆向弹幕、批量模拟点击或无人循环录播。

## 需要准备

1. 独立抖音账号。
2. 抖音开放平台账号及实名认证。
3. 创建应用，申请以下能力（按实际需要）：
   - `user_info`
   - `video.create`
   - 视频数据读取权限
   - 私信相关权限（如账号资质允许）
   - 直播玩法或直播伴侣相关能力
4. HTTPS OAuth 回调地址。
5. 凭证只存储在私有凭证保险库，不进入 Git。

## 接入后的流程

```text
小居居自主选题
→ 生成视频/直播内容草稿
→ 内容与合规检查
→ 用户授权发布账号
→ 抖音官方接口发布
→ 互动/评论/私信事件进入 Brain Gateway
→ 记忆、审计与反思
```

## 直播合规

- 画面持续显示“AI智能体/虚拟主播”。
- 必须有真人值守和停止开关。
- 实时回应为主，不播放循环录播冒充直播。
- 平台规则变化时暂停接入，不绕过风控。
