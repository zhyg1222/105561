# 对话风格与用户画像运行手册

## 问题诊断

2026-10-28 用户反馈“回答无聊”。根因不是单一模型能力，而是：

- 人格提示词强制短句，复杂问题被压成一句判断。
- `clean_chat_reply` 曾只保留两句话、最多 160 字。
- 主身份包没有加载用户长期画像，模型不知道用户为什么在意这些问题。
- 记忆只检索关键词，未命中时回答容易变成泛泛判断。

## 当前规则

- 先判断意图：闲聊、求判断、求方案、事实核查。
- 闲聊 2～4 句，具体、有反差，不硬问问题。
- 求判断/方案：先结论，再 2～3 个理由，再给下一步和验收标准。
- 事实问题先查再答，不确定就说不确定。
- 有相关旧记忆时自然回调，不念内部记忆列表。
- 不迎合、不空泛鼓励、不堆术语。
- AI 身份始终不可隐藏。
