# 小居居开源优先独立人格实施路线

> 日期：2026-10-26  
> 状态：待老大评审  
> 架构规格：`docs/architecture/2026-10-26-开源优先独立人格架构设计.md`

## 1. 拆分原则

这不是一个可以一次写完的代码任务。各阶段的成功标准、基础设施和失败代价不同，因此拆成五个可独立验收的计划。

每个阶段都必须：

- 先写失败测试。
- 产出可运行软件。
- 通过本阶段验收后才进入下一阶段。
- 不修改人格宪法、关系规则和 AI 标识。
- 不允许直接用 `latest` 镜像或依赖。
- 线上切换使用 feature flag，并保留回滚路径。

## 2. 计划顺序

### Plan 1：Agent 平台底座

**详细计划：** `docs/superpowers/plans/2026-10-26-01-agent-platform-foundation.md`

交付：

- 新 Python 包 `xiaojuju_agent`
- PostgreSQL、Valkey、Neo4j、OPA 的固定版本 Compose
- 幂等事件入口
- Celery 队列与重试
- LangGraph 对话图
- OpenAI-compatible 输出接口
- OPA 权限客户端
- 影子回放
- OpenTelemetry trace_id
- 健康检查

退出条件：

- 新系统能接收一条测试消息并产生回复。
- 重复事件不重复处理。
- 重启后 LangGraph thread 可以恢复。
- 影子模式绝不写外部 outbox。
- OPA 不可用时，有副作用工具 fail-closed。

### Plan 2：记忆与反思

交付：

- Graphiti + Neo4j 长期记忆
- Postgres 核心记忆命名空间
- 旧 JSONL / SQLite 数据迁移器
- 联系人隔离
- 时间事实和矛盾失效
- 异步记忆写入
- 夜间反思图
- 记忆来源追溯

退出条件：

- 旧事件成功导入。
- 召回可追溯到 event_id。
- 旧事实与新事实冲突时只注入有效事实。
- 反思不能修改人格宪法或扩大权限。

### Plan 3：手机与浏览器工具

交付：

- Mobilerun Phone Worker
- OPPO A97 验收集
- 微信发送幂等与发送后验证
- browser-use Web Worker
- 独立浏览器 Profile
- 工具预算、超时、步数上限
- OPA 与 LangGraph 审批接线

退出条件：

- 固定手机任务达到验收阈值。
- 手机断连不冒充成功。
- 浏览器公开发布必须审批。
- 工具结果能进入记忆候选，但不会自动污染核心记忆。

### Plan 4：社交、主动生活与直播切换

交付：

- 微信入站迁移
- 主动聊天迁移
- 自主生活图迁移
- 直播对话接到 Open-LLM-VTuber
- outbox 统一
- 频率、静默时段和联系人隔离
- 旧核心灰度退役

退出条件：

- 同一事件不会重复回复。
- 主动聊天遵守频率和最近聊天规则。
- 自主生活不强制日报。
- 直播保持统一人格和 AI 标识。

### Plan 5：观测、评估与生产部署

交付：

- Langfuse 自托管或 OTLP 接入
- 50 条人格回归集
- 记忆回归集
- 工具权限回归集
- 崩溃恢复与故障注入
- 云主机 + Windows 边缘机部署
- 备份、恢复、升级与回滚手册

退出条件：

- 可以回答“这次为什么这样回复、用了什么记忆、执行了什么工具”。
- 任一组件故障有明确降级。
- 数据可完整备份和恢复。
- 固定版本升级流程可演练。

## 3. 当前执行范围

只执行 Plan 1。Plan 2 至 Plan 5 在上一阶段通过验收后再写成同等粒度的任务计划，避免提前写死尚未验证的接口。

## 4. 统一质量门槛

- `ruff check`
- `ruff format --check`
- 完整 pytest
- PostgreSQL 集成测试
- OPA policy test
- 影子回放
- `git diff --check`
- 每个 Task 独立 commit
- 不使用真实账号做自动测试
- 不把私密配置、token、聊天正文写入 Git
